# ALL OR NOTHING HP — Cinematic Entrance Prototype

トップページに「店内へ入っていく」演出を追加した版です。

## 演出
1. 暗い店内からスタート
2. ロゴと入口が徐々に浮かび上がる
3. ENTERを押すと左右の深紅のカーテンが開く
4. 店内の光が強くなり、カメラが奥へ進むように背景がズーム
5. 金色の粒子が漂う
6. 約2秒後にABOUTへスムーズに移動

ENTERを押さずにSCROLLしても同様に入口演出を開始します。
